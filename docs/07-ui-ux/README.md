# UI/UX

Thư mục này mô tả trải nghiệm mục tiêu cho người thuê. Nó chưa xác nhận các màn hình mới đã được triển khai.

## Tài liệu

1. [Nguyên tắc giao diện](design-principles.md) — tính nhất quán, nội dung, responsive và accessibility.
2. [Luồng khám phá](discovery-flow.md) — nhập nhu cầu, bộ lọc và kết quả ban đầu.
3. [Kết quả và chi tiết tin](results-and-detail.md) — ranking, explanations, dữ liệu thiếu và giá tham khảo.
4. [Lưu và so sánh](save-and-compare.md) — thao tác không cần account và giới hạn local.
5. [Trạng thái và accessibility](states-and-accessibility.md) — loading, empty/error/stale/expired, bàn phím và hỗ trợ thiết bị.

## Nguyên tắc trạng thái

Mọi giao diện phải phản ánh trạng thái dữ liệu thực tế. Thiếu dữ liệu, dữ liệu cũ, tin hết hạn, gợi ý heuristic và ước lượng giá đều cần cách diễn đạt riêng, gần với quyết định liên quan. Dùng [quy tắc sản phẩm](../01-product/project-rules.md) làm nguồn sự thật về hành vi sản phẩm.
